### What I work on

Multi-tenant backends, service-to-service authentication, and the unglamorous parts around them —
schema isolation, idempotent replay, transactional outbox, rollback that actually restores something.
On the infrastructure side: Terraform, Ansible, and pipelines that go from a commit to a running
system without anyone opening an SSH session.

Most of my work lives on GitLab, including a self-hosted instance at work. The repositories here are
published copies, so the pipelines you see defined in them run elsewhere.

### Featured projects

| | |
|---|---|
| **[ASM Track](https://github.com/Moaziz667/asm-track)** | Multi-tenant delivery platform. 6 Spring Boot services, schema-per-tenant PostgreSQL, Keycloak OIDC, ERP adapters driving Odoo 16/19 and ERPNext from one codebase, and a RAG assistant scoped to each user's permissions. 271 REST endpoints, 580+ automated tests. |
| **[Driver App](https://github.com/Moaziz667/driverApp-asmtrack)** | The companion Flutter app, built offline-first. Actions are written to a local queue and replayed on reconnect, timestamped at the moment of the gesture rather than the moment of upload. |
| **[MoodTunes](https://github.com/Moaziz667/moodtunes)** | Flutter + Node.js on AWS. Terraform provisions the ALB, Auto Scaling Group and MongoDB Atlas; the pipeline then feeds the live load balancer DNS into the app's config before building the APK, so the network layer can be rebuilt without touching code. |
| **[Laravel Cloud Migration](https://github.com/Moaziz667/laravel-cloud-migration)** | One application moved from a hand-managed VPS to Terraform-provisioned AWS, with both targets kept alive and shipped by the same seven-stage pipeline — so the trade-offs could be measured instead of argued. |
